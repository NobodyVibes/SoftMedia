# Global Search

Find any media quickly using the search bar in the top navigation.

## How It Works

1. Click the search bar at the top of the screen
2. Start typing a title (minimum 2 characters)
3. Results appear in a dropdown, grouped by library

## Features

| Feature | Description |
|:---|:---|
| Library Grouping | Results are organized by library (Movies, TV, Music) |
| Quick Preview | Each result shows poster, title, and year |
| Direct Play | Click the play button to start immediately |
| Navigate to Details | Click anywhere else on a result to view details |

## Keyboard Shortcuts

- **Escape** - Close search results
- **Click outside** - Close search results

## Tips

- Search is case-insensitive
- Only top-level items are shown (series and albums, not individual episodes or tracks)
- Results are cached briefly for faster repeated searches
